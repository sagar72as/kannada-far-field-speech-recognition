Butterworth Bandpass Filter 5th-Order (80 Hz – 7500 Hz) eliminates out-of-band hiss
Delay-and-Sum (DS) Beamformer Spatial element-wise averaging across 4 array microphones
Theoretical Array Gain +6.02 dB $10\log_{10}(M = 4)$
Output Signal-to-Noise ~11.0 dB Spanned across 16 kHz
Filter Transfer Function Order 5 Butterworth IIR
Active Spatial Averaging Formulation:
$$y(t) = \frac{1}{M}\sum_{m=1}^{M} x_m(t - \tau_m) \quad \text{where} \quad \tau_m = \frac{(m-1)d\sin\theta}{c}$$

Correlated Kannada speech adds constructively in-phase, while ambient noise across the USB multi-microphone channels cancels destructively.
